# JavaScript Learning Roadmap

This branch is for learning JavaScript from beginner to advanced level.

प्रत्येक topic मध्ये:
- English explanation
- Marathi explanation
- Simple examples
- Expected output
- Practice questions
- Small exercises

## Learning Order

1. Introduction to JavaScript
2. Variables: var, let, const
3. Data Types
4. Operators
5. if / else Conditions
6. switch Statement
7. for Loop
8. while and do-while Loop
9. Functions
10. Arrays
11. Objects
12. Strings
13. Array Methods
14. DOM Basics
15. Events
16. ES6 Features
17. Promises
18. async / await
19. Fetch API
20. Mini Projects

## Rule

Do not only read the code. First understand the logic, predict the output, then execute it and solve the practice questions yourself.
