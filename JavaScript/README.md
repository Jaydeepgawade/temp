# JavaScript Learning Roadmap

This branch is for learning JavaScript from beginner to advanced level.

प्रत्येक topic मध्ये:
- English explanation
- Marathi explanation
- Simple examples
- Practice questions
- Small exercises

## Complete Learning Order

1. Introduction to JavaScript
2. Variables - `var`, `let`, `const`
3. Data Types
4. Operators and Conditions
5. Loops
6. Functions
7. Arrays
8. Objects
9. Strings, Numbers, Date and Math
10. Scope, Hoisting and Closures
11. DOM and Events
12. ES6+ Modern JavaScript
13. Classes and OOP
14. Callbacks, Promises and Async/Await
15. Fetch API, JSON and Browser Storage
16. Error Handling and Debugging
17. Modules and Clean Code
18. Advanced JavaScript Concepts
19. Practice Roadmap and Mini Projects

## Important Subtopics Covered

- Arithmetic, comparison, logical and ternary operators
- `if`, `else if`, `else`, `switch`
- `for`, `while`, `do...while`, `break`, `continue`
- Function declaration, expression, arrow functions, parameters and return
- Arrays and `map`, `filter`, `reduce`, `find`, `forEach`, `some`, `every`
- Objects, nested objects, `this`, destructuring and spread
- String methods, Number conversion, Math and Date
- Global/function/block scope, hoisting and closures
- DOM selection/manipulation and browser events
- Template literals, rest/spread, optional chaining and nullish coalescing
- Classes, constructors, inheritance and `super`
- Callbacks, Promise lifecycle, `async/await`
- JSON parse/stringify, Fetch API, localStorage/sessionStorage
- `try/catch/finally`, throw and browser debugging
- ES modules using `import` / `export`
- Execution context, call stack, event loop, microtasks
- Prototype chain, `call/apply/bind`
- Shallow/deep copy
- Debouncing and throttling
- Higher-order functions, pure functions, currying and memoization basics

## How To Learn / कसे शिकायचे

1. एकावेळी एक chapter वाच.
2. Example execute करण्याआधी output स्वतः predict कर.
3. Logic notebook वर लिही.
4. प्रत्येक chapter मधले कमीत कमी 5 practice questions solve कर.
5. Solution लगेच बघू नको; आधी स्वतः attempt कर.
6. Error आली तर `console.log`, DevTools आणि breakpoint वापर.
7. Basics complete झाल्यावर DOM projects सुरू कर.
8. शेवटी API आणि async projects complete कर.

> Goal: JavaScript syntax फक्त पाठ करायची नाही; logic समजून स्वतः code लिहिता आला पाहिजे.
