# 07 - Arrays

## English
An array stores multiple values in one variable.

```js
let numbers = [10, 20, 30];
console.log(numbers[0]);
```

### Important Methods
- `push()` add at end
- `pop()` remove from end
- `shift()` remove from start
- `unshift()` add at start
- `includes()` check value
- `indexOf()` find index
- `slice()` copy part
- `splice()` add/remove items
- `forEach()` iterate
- `map()` transform
- `filter()` filter values
- `find()` find first match
- `reduce()` combine values
- `some()` any match?
- `every()` all match?

## मराठी
Array म्हणजे एकाच variable मध्ये अनेक values ठेवण्याची पद्धत. Index ने value access करतो आणि index `0` पासून सुरू होतो.

`map` नवीन array बनवतो, `filter` condition match होणाऱ्या values ठेवतो, आणि `reduce` अनेक values पासून एक final result तयार करतो.
