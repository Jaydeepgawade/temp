5. Largest of three numbers.
6. Grade calculator.

एक topic वाचल्यावर लगेच कमीत कमी 5 questions स्वतः solve कर. Code copy करू नको. आधी logic notebook वर लिही, मग JavaScript code लिही. Error आली तर console आणि DevTools वापरून स्वतः trace कर.
