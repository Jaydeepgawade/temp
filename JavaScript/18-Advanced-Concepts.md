# 18 - Advanced JavaScript Concepts

## English
These concepts are important after you are comfortable with the fundamentals.

### Topics
- Execution context
- Call stack
- Event loop
- Web APIs
- Task queue and microtask queue
- `this` keyword
- `call`, `apply`, `bind`
- Prototypes and prototype chain
- Shallow vs deep copy
- Pass by value vs reference behavior
- Debouncing and throttling
- Higher-order functions
- Pure functions
- Currying basics
- Memoization basics

## मराठी
हे topics JavaScript आतून कसा काम करतो हे समजण्यासाठी आहेत. Event loop मुळे asynchronous callbacks योग्य वेळी execute होतात. Prototype chain मुळे objects properties/methods inherit करू शकतात.

Debounce म्हणजे वारंवार event आला तरी थोडा वेळ थांबून एकदाच function चालवणे. Search textbox हे common example आहे. Throttle मध्ये ठराविक interval मध्ये function execute होतो.
