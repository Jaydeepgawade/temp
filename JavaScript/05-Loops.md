# 05 - Loops

## English
Loops repeat a block of code until a condition is false.

### for loop
```js
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```

### while loop
```js
let i = 1;
while (i <= 5) {
  console.log(i);
  i++;
}
```

### do...while
```js
let n = 1;
do {
  console.log(n);
  n++;
} while (n <= 5);
```

### break and continue
- `break` stops the loop.
- `continue` skips the current iteration.

## मराठी
Loop म्हणजे एकच code पुन्हा पुन्हा चालवणे. `for` loop तेव्हा चांगला जेव्हा iterations माहिती असतात. `while` मध्ये condition true असेपर्यंत loop चालतो.
