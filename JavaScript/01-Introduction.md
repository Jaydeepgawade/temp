# 01 - Introduction to JavaScript

## English
JavaScript is a programming language mainly used to make web pages interactive.

HTML gives structure to a webpage.
CSS gives design and styling.
JavaScript gives behaviour and logic.

Example: when you click a button and something changes on the page, JavaScript is usually responsible for that behaviour.

## मराठी
JavaScript ही एक programming language आहे जी website ला dynamic आणि interactive बनवण्यासाठी वापरली जाते.

HTML = webpage ची structure
CSS = webpage चे design
JavaScript = webpage चे logic आणि behaviour

उदाहरण:
Button वर click केल्यावर message दाखवणे, form validate करणे, data fetch करणे, calculation करणे इत्यादी JavaScript ने करता येते.

## First Example
```javascript
console.log("Hello Jaydeep");
```

Output:
```text
Hello Jaydeep
```

`console.log()` म्हणजे console मध्ये output print करणे.
