# C# DSA Learning Roadmap

This branch teaches C# problem-solving from number basics to foundational
collections and then to advanced algorithms.

## Chapter Order

1. Reverse Number
2. Palindrome Number
3. Armstrong Number
4. Count Digits
5. Sum of Digits
6. Prime Number
7. Factorial
8. Fibonacci Series
9. Print Only Non-Duplicate Values
10. `List<T>`
11. `Dictionary<TKey, TValue>`
12. `HashSet<T>`
13. `Stack<T>`
14. `Queue<T>`
15. Graph Basics, BFS, and DFS
16. Greedy Algorithm Basics
17. Dynamic Programming Basics

Complete chapters 10–14 before beginning Graph traversal because Graph examples
depend on lists, dictionaries, sets, stacks, and queues.
